LLM 全链路 Trace 实践

用 OpenTelemetry 构建大模型应用的观测体系，从指标、日志到分布式追踪。

为什么传统 APM 不够用

大模型应用的调用链有一个特殊问题：每次请求的 Prompt 和输出都不一样，只看延迟和错误率无法定位「为什么这条回答质量差」。

Trace 设计

基于 OpenTelemetry 自定义 Span，把 Prompt 版本、Token 数、模型名、检索命中的文档列表都挂到 trace 上，再通过 Grafana 做可视化看板。

效果

上线后 MTTR 下降 60%，内容安全双通道（敏感词+模型审核）实现注入拦截 99% 以上、误拦低于 2%，可用性 SLO 达到 99.9%。
